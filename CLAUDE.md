- Resolve technical implementation decisions autonomously from current source,
  runtime behavior, and the repository contract. This includes numeric limits,
  schema/handler alignment, parser behavior, error codes, refactor boundaries,
  tests, packaging, and runtime verification.

  for adjudication. Choose the smallest correct route, implement it, and report
  the result in plain language.
- Ask the owner only for product value or direction, visible experience
  preference, release/deploy/publication intent, credentials, spending,
  legal/privacy exposure, or another genuinely owner-only authorization.
